# save-research - 調査内容のmarkdown保存

セッション内で調査した内容を、後から読み返せるドキュメントとしてまとめて保存する。

## 保存先

```
${HOME}/Google Drive/マイドライブ/Docs/LLM/yyyymmdd_タイトル.md
```

- `yyyymmdd` は保存日（例: `20260825_ALBアクセスログ調査.md`）
- タイトルは内容が一目でわかる日本語の短い名前（スペースは使わずアンダースコアかそのまま連結）
- パスは必ず `$HOME` から解決する（ハードコード禁止）
- 同名ファイルが既にある場合は、内容を確認したうえで追記するか、`_2` などを付けて別ファイルにするかユーザーに確認する

## 手順

1. 日付を取得する

   ```bash
   date +%Y%m%d
   ```

2. 保存先ディレクトリの存在を確認する
3. 会話内の調査結果を下記フォーマットでまとめ、ファイルに書き出す
4. 保存後、保存先のフルパスをユーザーに報告する

## まとめかたの方針

- シンプルにリスト（箇条書き）を主体にする
- 文章の段落は最小限にし、だらだら書かない
- カテゴリごとに段落（見出し）を分けて記載する
- 1つの見出しに詰め込みすぎず、話題が変わったら見出しを分ける
- コマンドや設定は必ずコードブロックにする
- 参照したURL・ファイルパスは末尾にまとめる

## フォーマット

```markdown
# <タイトル>

- 日付: yyyy-mm-dd
- 概要: <何を調べたか1〜2行>

## <カテゴリ1>

- <要点>
- <要点>

## <カテゴリ2>

- <要点>

```bash
<コマンド例>
```

## 結論・対応方針

- <結論>
- <次のアクション。無ければ省略>

## 参考

- <URL / ファイルパス>
```

## 注意

- 出力は日本語、絵文字なし
- シークレット（トークン、パスワード、APIキー、アカウントIDなど）は記録しない
- 会話ログの全文コピーではなく、後から読んで役に立つ要点にする
